تطبيق **"قرآني"** هو رفيقك الإيماني في رحلة القرآن الكريم، صُمم ليجمع بين **فخامة التصميم** و**قوة التقنية**. يوفر التطبيق تجربة فريدة للاستماع للمصحف الشريف بأصوات نخبة من القراء، مع ميزات ذكية مدعومة بالذكاء الاصطناعي وأدوات دينية شاملة.

---

### ✨ المميزات الرئيسية

*   **🎧 رحلة صوتية فريدة:** استمع لأكثر من 30 قارئاً من مشاهير القراء بجودة عالية.
*   **🤖 مساعد ذكي (AI):** مساعد ديني متكامل مبني على تقنيات Gemini للإجابة على تساؤلاتك الدينية وتوجيهك داخل التطبيق.
*   **📸 كروت المشاركة:** ميزة مبتكرة لتوليد صور احترافية للآيات القرآنية بتصميمات فخمة جاهزة للمشاركة على منصات التواصل الاجتماعي.
*   **📚 التفسير المزدوج:** دعم لعدة محركات تفسير (الميسر، الجلالين، القرطبي، إلخ) لفهم أعمق لمعاني الآيات.
*   **📱 تطبيق ويب متطور (PWA):** سرعة فائقة، إمكانية التثبيت على الهاتف، ودعم كامل للعمل بدون إنترنت (Offline) للسور المحملة.
*   **🎨 واجهة مستخدم زجاجية:** تصميم عصري يعتمد على الـ (Glassmorphism) مع خلفيات (Mesh Gradients) متغيرة الألوان لراحة العين.
*   **🛠️ أدوات إيمانية متكاملة:**
    *   مواقيت صلاة دقيقة بناءً على موقعك الجغرافي.
    *   سبحة إلكترونية بليبرة (Haptic Feedback) عصرية.
    *   دعاء متجدد يومياً لمواكبة روتينك الإيماني.
    *   مؤقت نوم ذكي للإيقاف التلقائي للصوت.

---

### 🛠️ البناء التقني (Tech Stack)

تم بناء التطبيق باستخدام أحدث تقنيات الويب لضمان السرعة والاستقرار:

*   **Core:** Vanilla JavaScript (ES6+), HTML5, CSS3.
*   **Styling:** Custom CSS with Glassmorphism patterns & Dynamic Mesh Gradients.
*   **AI Service:** Integrated with Google Gemini API for the smart assistant.
*   **PWA:** Service Workers for caching and offline capabilities.
*   **Media:** Media Session API for advanced lock-screen control and branded artwork.
*   **Canvas API:** For generating professional shareable ayah cards.
*   **APIs:** Al Quran Cloud API, Islamic Prayer Times API.
